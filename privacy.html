プライバシーポリシー

  • この道具は、本人が許可した YouTube チャンネルへ動画を投稿するためだけに、YouTube Data API を使います。
  • 許可の情報は本人の PC の中にだけ保存し、第三者に渡しません。広告・分析・販売には使いません。
  • 本人以外の利用者の情報は集めません。許可は Google アカウントの設定からいつでも取り消せます。
  • This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Privacy Policy

  • This tool uses the YouTube Data API only to upload videos to YouTube channels that the owner has authorized.
  • Authorization data is stored only on the owner's own PC and is never shared with third parties, nor used for ads, analytics or sale.
  • No data about anyone other than the owner is collected. Access can be revoked at any time from the Google Account settings.
